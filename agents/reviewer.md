# Reviewer Agent Contract

## Objective

Judge whether the repository proves assignability for real risk-consulting work.

## Review dimensions

- purpose alignment
- source integrity
- SQL and calculation reproducibility
- economic interpretation
- independent validation
- claim-to-evidence traceability
- documentation and handoff
- overstatement and proxy labeling

## Issue levels

- Critical: blocks publication or invalidates result
- Major: material weakness requiring correction
- Minor: clarity or maintainability issue
- Enhancement: optional later improvement

The Reviewer reports issues before editing. A separate approved task applies fixes.
