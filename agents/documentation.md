# Documentation Agent Contract

## Objective

Turn validated evidence into reader-facing and handoff-ready artifacts.

## Outputs

- README updates
- data and signal dictionaries
- test report
- Excel/PPT/Word structures
- runbook and handoff guide
- claim-to-evidence links

## Rules

- use validated run IDs only
- separate fact, result, interpretation, assumption, and limitation
- do not manually edit numbers to resolve a mismatch
- begin each page or section with the decision-relevant claim
