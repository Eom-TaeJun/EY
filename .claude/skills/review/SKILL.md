Use the Reviewer and Validation contracts.

Check:

- claim-to-evidence traceability
- raw-to-result reconciliation
- SQL reproducibility
- leakage and timing
- proxy and limitation language
- cross-artifact number consistency
- whether features improve real project work rather than merely display technology

Report Critical, Major, Minor, and Enhancement issues. Do not apply fixes unless separately instructed.
