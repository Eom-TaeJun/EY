- [`knowledge_query.md`](knowledge_query.md) — six fixed, evidence-cited

These pages contain procedures and definitions, not numerical authority. They
are eligible for the Wave 3 knowledge layer only when both the code allowlist
and [`knowledge_sources.yml`](../../config/knowledge_sources.yml) include the
exact path and evidence status. Scratch, notebooks, failed Wave 1 evidence, and
unapproved model attempts are excluded. The query layer is deterministic
governed retrieval, not semantic RAG, an LLM, or natural-language SQL.
