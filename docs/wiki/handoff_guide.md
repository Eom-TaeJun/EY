# Handoff Guide

A new analyst should be able to answer:

- What business problem does the project solve?
- Which data is canonical?
- How is each table and signal defined?
- Which tests protect the outputs?
- Which decisions remain assumptions?
- What failed in the latest run?
- How can the latest validated result be reproduced?
- Which portfolio claims depend on that result?

Recommended reading order:

1. README
2. project charter
3. current project state
4. data dictionary
5. test catalog
6. decision ledger
7. latest work status
8. runbook
