# MVP and Extension Scope

## Same-day minimum

1. Harness and repository map
2. source registration and raw ingestion contract
3. PostgreSQL schemas
4. wide-to-long customer-month transformation
5. at least 12 SQL quality or business-rule tests
6. at least 5 behavioral risk signals
7. default-rate comparison by signal and explainable risk band
8. README, test report, and evidence map

## Parallel preparation

- data dictionary
- graph schema
- validation interfaces
- output templates
- Wave 2 model contracts

## Later Waves

- PD model comparison and calibration
- Stage proxy and sensitivity
- LGD/EAD with suitable data
- macroeconomic scenario linkage
- data lineage graph
- RAG and LLM Wiki
- report generation and agent automation

## Scope rule

Do not remove later modules from the architecture. Defer their implementation while preserving interfaces and documentation locations.
