# Risk Component Scope

## Wave 1

- focus: data integrity and PD-related behavioral signals
- allowed claim: early-warning and observed default separation prototype
- not supported: LGD, EAD, lifetime ECL, official SICR or Stage assignment

## Wave 2

- compare explainable PD models
- perform time-aware or pseudo-temporal validation where data permits
- introduce Stage proxy only with explicit assumptions
- use EAD proxy only if clearly labeled

## Later data extension

Implement LGD and EAD only with data containing default exposure, recovery, cost, collateral, and timing fields.

## Language controls

Use:

- prototype
- proxy
- simulation
- public-data implementation

Do not use:

- official IFRS 9 model
- production bank model
- regulatory-compliant calculation
