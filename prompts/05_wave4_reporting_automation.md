# Wave 4 Reporting and Automation Prompt

## Objective

Automate recurring, reversible project work while preserving human approval for material definitions and publication.

## Work

- orchestrate Hermes, Builder, Validator, Graph, Wiki, Reporter, and Reviewer roles
- automate test execution, run registration, issue creation, lineage update, and output generation
- generate Excel test workbook, PPT story, Word methodology report, and handoff package
- ensure all numbers are read from validated run outputs
- add regression and cross-artifact consistency checks
- document recovery, rerun, and approval steps

## Approval boundaries

Require human approval for destructive actions, definition changes, threshold changes, final interpretations, and external publication.
